# 🔐 Interface de Login com JavaFX

Projeto simples desenvolvido em Java utilizando JavaFX + FXML para praticar:

- Navegação entre telas
- Estrutura com FXML
- Controllers
- Estilização com CSS
- Lógica simples de autenticação
- Organização de projeto JavaFX com Maven
- Tratamento de erros
- Alertas com Alert
- Validação de campos vazios

---

##  Tecnologias utilizadas

- Java 21
- JavaFX
- FXML
- CSS
- Maven
- IntelliJ IDEA
- Scene Builder
